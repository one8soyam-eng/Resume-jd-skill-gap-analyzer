# Resume-to-JD Match & Skill Gap Analyzer

An interactive data science and NLP web application built with **Python**, **Scikit-Learn**, **Matplotlib**, **Seaborn**, **`pypdf`**, and **Streamlit** to evaluate resume-to-job-description alignment, identify skill gaps, and simulate "What-If" match score improvements.

## Features
- **PDF & Text Resume Input:** Upload PDF resumes via `pypdf` or paste/edit resume text and job descriptions directly.
- **Match Score & Skill Gap Analysis:** Computes similarity and skill overlap to highlight matched, missing, and additional skills.
- **Visual Breakdown:** Displays skill coverage charts using Matplotlib and Seaborn.
- **Interactive "What-If" Simulator:** Simulates how adding missing skills impacts the overall match score.
